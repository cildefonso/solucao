# criar-pop-ups-funcionalidadeangular

Skill para implementar, em uma aplicação Angular legada, um pop-up de seleção quando a pesquisa por CPF retornar mais de um benefício.

A skill preserva os fluxos por NB e NIT, exige inspeção do contrato real da API, orienta a reutilização do fluxo existente e inclui critérios de acessibilidade, segurança, testes e evidências.
