# Checklist de aceite

## Inspeção
- [ ] HTML, TypeScript, SCSS, service e modelos localizados
- [ ] `package.json` e versão do Angular verificados
- [ ] Biblioteca de modal existente identificada
- [ ] Contrato real da API identificado
- [ ] HTML de referência analisado quando disponível

## Funcionalidade
- [ ] Zero benefícios mantém tratamento atual
- [ ] Um benefício mantém fluxo atual
- [ ] Múltiplos benefícios abrem pop-up
- [ ] Lista apresenta todos os itens retornados
- [ ] Seleção exclusiva
- [ ] Continuar desabilitado sem seleção
- [ ] Confirmar reutiliza o fluxo existente
- [ ] Cancelar não continua o fluxo
- [ ] NB e NIT continuam funcionando

## Qualidade
- [ ] Sem subscriptions duplicadas
- [ ] Sem `innerHTML`
- [ ] Sem dados pessoais em logs
- [ ] Modal acessível por teclado
- [ ] Layout responsivo
- [ ] Testes atualizados
- [ ] Lint executado
- [ ] Build executado
- [ ] Evidências registradas
