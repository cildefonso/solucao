# Checklist operacional

## Antes
- [ ] Árvore de trabalho inspecionada
- [ ] Branch e restauração definidos
- [ ] Versões coletadas
- [ ] Registry, proxy e certificados preservados
- [ ] Lockfile identificado
- [ ] Dependências inventariadas
- [ ] Pipeline, Docker e output revisados
- [ ] Destino estável confirmado oficialmente
- [ ] Matriz de compatibilidade iniciada
- [ ] Identificadores de evidências definidos

## Para cada major
- [ ] Compatibilidade do Node.js e TypeScript confirmada
- [ ] Core, CLI e Material/CDK alinhados
- [ ] Migrations revisadas
- [ ] Correções manuais documentadas
- [ ] Instalação limpa aprovada
- [ ] Lint aprovado
- [ ] Testes aprovados, quando existentes
- [ ] Build de produção aprovado
- [ ] Runtime validado
- [ ] Diff revisado
- [ ] Comandos, códigos de saída e resultados registrados
- [ ] Evidências vinculadas
- [ ] Checkpoint registrado

## Final
- [ ] Fluxos críticos validados
- [ ] Pipeline aprovado
- [ ] Artefato e deploy confirmados
- [ ] Vulnerabilidades avaliadas
- [ ] Documentação atualizada
- [ ] Rollback documentado
- [ ] Matriz e índice de evidências completos
- [ ] Dados sensíveis removidos
- [ ] Pull request preparado
